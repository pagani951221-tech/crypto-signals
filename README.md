# 加密貨幣操作建議

用 Binance 公開行情做技術分析回測，依一條經過驗證的規則給出做多／放空建議、止損止盈價與建議倉位。純前端，不需要金鑰或伺服器。

## 使用

- 直接用瀏覽器開 `index.html`，或用任何靜態伺服器（例如 GitHub Pages）。
- 每次開啟會掃描 Binance 成交量前 50／100／150 名（可選；預設只看 Ourbit 買得到的幣，也可改成不限交易所；排除穩定幣、黃金代幣與上市未滿 18 個月的標的），格子只顯示現在可進場或持有中的幣。想看其他幣，用「查看其他幣」選單挑選或輸入任何代號，該幣才會單獨下載。
- 選擇週期、本金、每筆風險 % 與盈虧比；勾選自動更新後，每根 K 線收盤會重算並在有新訊號時通知（頁面需保持開啟）。

## 台股（實驗性）

網頁上方「市場」選「台股（實驗性）」。`tw-scan.js` 由 `.github/workflows/tw.yml` 在每個交易日台灣時間 14:40 執行：抓上市＋上櫃全部普通股（證交所、櫃買中心開放資料，約 1,900 檔）與 Yahoo Finance 還原權息日線，用台股專用規則（`tw-rule.js`）與台股成本（一來一回約 0.785%）計算，寫入 `tw.json` 給網頁讀，並把新的進場與出場傳 Telegram。

台股規則：收盤創 52 週新高、當天成交金額是近 20 天平均的 2 倍以上、而且當下已公布的最新月營收創 12 個月新高，隔天開盤買進；止損 3 ATR，沒有固定止盈，收盤跌破 50 日均線出場，最多 60 個交易日。進場當下近 20 天平均每天成交要 1,000 萬元以上。原本加密貨幣的規則用在全部台股時扣掉成本幾乎不賺錢（平均每筆 +0.16%，驗證未通過），所以另外研究（`research8.js`）：20 種常見股票規則裡，短線反彈類全部虧錢，只有「新高＋放量、跌破均線才賣」的長抱型在 2016–2021 挑、2022 年起驗證時仍賺錢。加上營收濾網（`research9.js`）後平均每筆從 +2.7% 提高到 +4.1%，2016–2021 與 2022 年起兩段都變好；營收衰退的股票成績最差。月營收來自公開資訊觀測站每月彙總表（M 月營收 M+1 月 11 日起才使用），歷史存在 Actions 快取，每天只補抓缺的月份。新聞沒有可回測的歷史資料，所以不列入判斷，網頁只附 Yahoo 股市的新聞、月營收、EPS 連結。三大法人買賣超（`research10.js`，2018 年起）：外資、投信、三大法人 5 日或 20 日買超等 6 種條件，都沒有讓 2021 年前與 2022 年起兩段同時變好（外資賣超的反而比較好），所以不列入規則，網頁只顯示最近 5 個交易日的買賣超供參考。驗證區下方可展開「今年漲最多的股票，規則有沒有抓到」：漲幅前 30 名與規則今年的進出場或沒進場的原因，只用來檢查規則；另外驗證過，年初用站上 200 日均線、成交量大、營收成長來挑股票，2018–2025 年並沒有比較容易挑到翻倍股，所以不做成選股條件。出場方式（`research11.js`）：持有上限改 90／120 天、改用 20／100 日均線、改用移動停利、止損改 2／4 ATR 都測過。只有拉長持有上限讓兩段平均都變高，但幾乎全來自 2025 年少數大漲股，2016–2024 年只從 +2.97% 變 +3.11%（t 值反而下降），拿掉前 1% 大贏家後反而變差，所以維持 50 日均線＋60 天。漲跌停（`research12.js`）：隔天開盤就漲停的只有 2%，一字漲停整天買不到的 0.7%；把買不到的放棄、跌停賣不掉的順延到隔天開盤賣，平均每筆從 +4.12% 變 +3.99%，2021 年前與 2022 年起都仍賺錢，影響不大（進場要求每天成交 1,000 萬元以上有幫助）。處置股沒有歷史資料，沒有模擬。帳戶模擬（`research13.js`）：同時最多 N 檔、每檔用總資產 1/N，訊號太多時隨機挑（跑 50 次）。2017 年起最多 10 檔年化約 +32%、最大回落約 −31%，同期 0050 年化 +22%、最大回落 −34%；2021 年起約 +42%（0050 +24%）。只持有 5 檔時回落可達 −46%～−59%，20 檔最穩。（2026/11/8 修正：舊版模擬當天進當天出的交易會一直佔住名額，低估了報酬。）真實紀錄：雲端每天把發出的訊號寫進 `tw-log.json`（只新增、不重算，進場價用訊號隔天實際開盤價），網頁「上線以來的真實紀錄」顯示這份沒有事後調整的成績。轉弱出場（`research17.js`）：大盤跌破 20／50 日均線、從 20 日高點回落 8%、市場寬度低於 40% 就全部出場，或個股連 2 天收在 20 日均線下、獲利 20% 後改用 20 日均線、從最高回落 15%、比大盤弱 10% 就出場，共 10 種；每筆平均全部變差，帳戶模擬也沒有同時讓報酬更高、回落更小（大盤轉弱就出場的年化只剩 +6%～+15%，回落反而更大），所以維持原規則，網頁只顯示大盤狀態與每檔持股的轉弱檢查供參考。保本出場（`research18.js`）：持有期間最高收盤曾賺到 10%／15%／20%／30% 後，止損拉到成本價（含交易成本）。每筆平均變低（+4.12% → +3.38%～+4.07%），但資金比較快空出來，帳戶模擬（10 檔）年化從 +32.1% 變 +32.6%～+36.3%、最大回落差不多（−30%～−32%）。所以不改規則，做成網頁設定「保本出場」（預設不使用）：開啟後持股會顯示保本線，收盤回到成本以下就標成「保本出場」。這個設定存在自己的瀏覽器，Telegram 通知仍照原規則。保本出場後重新進場（`research19.js`）：保本出場後 60 個交易日內，收盤再創前一段持有期間的最高收盤就重新進場，帳戶年化略高（曾賺 10%：+36.3% → +36.9%；15%：+35.7% → +36.4%），但最大回落變大 2～4 個百分點；改用「站回 20 日均線」重新進場則變差。網頁的保本設定採用「再創新高就重新進場」，各級設定的部位（含保本出場、等待重新進場）由雲端照同一套程式算好放在 tw.json。下市股票（`research14.js`）：用證交所 MI_INDEX、櫃買 otc 每日全部行情（2017 年起，含下市股票）重組未還原的日線，2017 年後下市且有足夠資料的 111 檔裡 61 檔曾觸發規則（161 筆，平均 −3.4%）；加進去後不加營收濾網的規則平均每筆從 +2.14% 變 +2.04%，前後段都仍賺錢。下市公司查不到月營收，所以含營收濾網的版本無法直接測。處置股（`research15.js`）：用證交所 punish、櫃買 disposal 公告（2017 年起 3,761 次處置）比對，進場日已是處置股的只有 57 筆（1.8%），平均 +16%，擋掉反而變差，所以規則不避開；持有期間才被處置的 418 筆平均 +40%（大漲才會被處置，不能拿來當條件）。雲端每天抓最新處置公告，網頁與 Telegram 會標出處置期間、幾分鐘撮合一次、要不要預收款券。注意股（`research16.js`）：用證交所 notice、櫃買 attention 公告（2017 年起 56,226 次）比對，訊號當天是注意股的 652 筆平均 +8.6%，比不是的（+3.0%）還好，訊號前 10 天被注意越多次的也越好；避開注意股會讓規則變差（+4.12% → +2.85%），所以不避開。網頁與 Telegram 只標出最近 10 個交易日被注意幾次，提醒可能變成處置股。訊號也提醒：隔天若一字漲停整天買不到就放棄這筆（研究十二：放棄或追價結果差不多）。這條規則勝率約三成，靠少數大漲的股票撐起平均；2017 年整年虧錢，2018、2022 年接近打平。Yahoo 只有目前仍上市櫃的股票，下市的抓不到，成績會偏高；研究十四用證交所、櫃買中心每日全部行情（含下市股票）估計，偏高約每筆 0.1 個百分點，影響不大。

## Telegram 通知

`.github/workflows/notify.yml` 在 GitHub Actions 執行 `scan.js`，掃描成交量前 100 名並傳 Telegram：每天台灣時間 08:10（日線收盤後）通知新的進場訊號與持有到期的部位；每小時檢查持有中的部位，碰到止損或止盈就提醒出場（同一筆只通知一次，紀錄存在 Actions 快取）。需要在倉庫的 Settings → Secrets and variables → Actions 設定 `TELEGRAM_BOT_TOKEN` 與 `TELEGRAM_CHAT_ID`。Actions 頁面可手動執行並傳測試訊息。本機試跑：`node scan.js`（沒設定這兩個值時只印出訊息）。

## 規則

站上 200 均線 ＋ MACD 在訊號線上 ＋ 突破前 20 根高點時做多，止損 3 ATR、止盈＝止損 × 盈虧比（頁面可設定，預設 2 倍、最低 1.5 倍），20 根 K 線內都沒碰到就出場。放空版（條件反過來）作為對照。因為有到期出場與交易成本，實際盈虧比會比設定值低：設 2 倍時實際約 1.5。

每次開啟都把掃描到的所有幣（約 100 個）合併做逐年滾動驗證：每年 1 月 1 日只用當時已結束的交易判斷是否允許當年交易，允許年份的成績與到目前的整體統計都通過，才會給出訊號。成本含手續費 0.1%、滑價 0.05%（單邊），放空以每 8 小時 0.01% 估計資金費率。歷史行情一律來自 Binance；`ourbit.json` 是 Ourbit 買得到的幣，由 `.github/workflows/ourbit.yml` 每週更新。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 建議頁面 |
| `strategy.js` | 指標、回測、驗證、倉位計算（瀏覽器與 Node 共用）；`node strategy.js` 自我檢查，`node strategy.js 1d` 印出驗證結果 |
| `research.js` | 止損／止盈網格研究：勝率與盈虧比的取捨 |
| `research2.js` | 同一規則在 10 個幣上合併驗證 |
| `research3.js` | 滾動式驗證：每年用之前資料重新挑規則 |
| `research4.js` | 盈虧比 ≥ 1.5 時各種止損距離的滾動驗證比較 |
| `research5.js` | 短週期（4 小時、1 小時、15 分鐘）的量價與資金費率反向策略：144 種組合，前 70% 挑、後 30% 驗；結果沒有一種在後段仍賺錢 |
| `research6.js` | 資金費率套利（現貨＋放空合約）：歷史年化約 10%，但集中在 2020–2021，2025 年後接近 0 |
| `research7.js` | 台股（上市市值前 150 大，Yahoo 還原權息日線、台股成本約 0.785%）：原規則技術上通過，但只有 2024 年起被允許交易，成績集中在近三年的多頭 |
| `research8.js` | 台股專用規則：上市櫃全部普通股、20 種規則（趨勢突破、52 週新高放量、RSI(2) 反彈、布林下緣拉回，各有／沒有大盤濾網），逐年滾動挑選與前後段驗證。用法：`node research8.js`（可加本機快取檔） |
| `research9.js` | 台股規則加月營收濾網：年增 > 0／> 20%、近 3 個月年增、創 12 個月新高，前後段比較，以及把濾網放進規則實際跑的結果 |
| `research10.js` | 台股規則加三大法人買賣超濾網（證交所 T86、櫃買 dailyTrade，2018 年起；只用訊號日前一天為止的資料）：外資／投信 5 日買超、投信連續買超、20 日買超，以及賣超對照組 |
| `research11.js` | 台股規則的出場方式：持有上限 40／90／120／250 天、跌破 20／100 日均線、不用均線、從最高收盤回落 3／5 ATR、止損 2／4 ATR，前後段與逐年比較 |
| `research12.js` | 台股規則的漲跌停成交：隔天開盤漲停比例、一字漲停買不到時放棄或順延追價、一字跌停賣不掉順延，前後段與逐年比較 |
| `research13.js` | 台股規則的帳戶模擬：同時最多 5／10／20 檔、等權重、訊號太多時隨機挑 50 次，年化、最大回落、多久沒創新高、最多連虧幾筆，和買進持有 0050 比較 |
| `research14.js` | 倖存者偏差：用每日全部行情（含下市股票）組日線，比較只有存活股票與加上下市股票的規則成績 |
| `research15.js` | 處置股：進場日已在處置中、持有期間才被處置、都沒有，三組報酬比較，以及進場日在處置中就不買的實際結果 |
| `research16.js` | 注意股：訊號當天是否注意股、訊號前 10 天被注意次數分組比較，以及避開注意股的實際結果 |
| `research17.js` | 轉弱就出場：大盤跌破均線、大盤回落、市場寬度、個股跌破 20 日均線、獲利後收緊、從高點回落、比大盤弱，每筆成績與帳戶模擬（10 檔）的年化與最大回落 |
| `research18.js` | 保本出場：曾賺 10%／15%／20%／30% 後回到成本就出場，每筆成績與帳戶模擬（10 檔）的年化與最大回落 |
| `research19.js` | 保本出場後重新進場：再創前一段新高、或站回 20 日均線，每筆成績、重新進場那幾筆的成績與帳戶模擬 |

研究腳本用法：`node research3.js 1d BTC ETH BNB SOL XRP DOGE ADA AVAX LINK TRX`（需要 Node 18 以上）。

## 免責聲明

歷史回測不保證未來獲利，這不是投資建議。放空需使用合約並承擔槓桿與強制平倉風險。
